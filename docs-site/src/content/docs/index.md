Secuarden records activity from supported coding agents so you can inspect changes,
check stored evidence, and understand the limits of capture.

## Start with one captured session

1. [Install the CLI](/secuarden-cli/get-started/install/).
2. Configure [Claude Code](/secuarden-cli/agents/claude-code/) or [Codex](/secuarden-cli/agents/codex/).
3. [Capture a session and inspect its evidence](/secuarden-cli/get-started/first-session/).

## What the evidence means

Secuarden records what supported integrations deliver. Configuration compliance,
live delivery, and stored-record integrity are different checks. Missing evidence
is not proof that no activity occurred.

This site is the initial documentation scaffold. See [versions and upgrades](/secuarden-cli/releases/)
before using development commands with an installed release.
